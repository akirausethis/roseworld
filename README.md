# 🌸 Roseworld — Personal Portfolio Website
### Rosdyanti Br Simarmata | Interactive Digital School Scrapbook

A personal portfolio website for **Rosdyanti Br Simarmata** (Rosee) — Law Student at Universitas Jambi and visual media enthusiast. Designed and built with a playful, handmade **school scrapbook / colorful editorial** aesthetic inspired directly by her original portfolio and CV.

---

## 🎨 Visual Identity & Features

- **Aesthetic**: School scrapbook, handmade collage, corkboard, notebook paper, school locker, stickers, polaroid frames, and washi tapes.
- **Color Palette**: Vibrant Pink (`#EA3D91`), Locker Green (`#168B5E`), Notebook Blue (`#1760D5`), Warm Orange (`#F58B25`), Sticky Yellow (`#FFF8B8`), and Cream Paper (`#FFFBF2`).
- **Typography**: Display poster typography (*Barrio*, *Fredoka*), authentic handwriting (*Caveat*, *Patrick Hand*), and clean editorial sans-serif (*Plus Jakarta Sans*).
- **Sections**:
  1. **Cover / Intro**: Notebook background, spiral binder, playful typography, original cutout portrait, and the iconic cat sticker.
  2. **Get to Know Me!**: Green locker background, pink grid panel, portrait in scrapbook frame, "ROSEE" badge, and verified academic interests.
  3. **Skills & Experiences**: Corkboard layout with 3 paper notes (Creative & Visual Media, Hukum & Technical Skills, Personal & Leadership).
  4. **Organizational Experience**: Law Science Organization (Moot Court), Cinema FH UNJA, OSIS SMA Sisingamangaraja, and Pramuka Jamcab.
  5. **Committee Experience**: Unja Law Fair 2026 (PDD Nasional) and Natal FH 2026 (PDD Internal).
  6. **Desain Gambar ("My Little Creations")**: Corkboard gallery featuring 11 authentic extracted artworks with interactive lightbox modal.
  7. **Prestasi & Sertifikat**: Pinned certificate from Universitas Mikroskil with modal view and regional achievements.
  8. **Riwayat Pendidikan**: Notebook-ruled paper timeline (Universitas Jambi & SMA Sisingamangaraja).
  9. **Kontak / Closing**: Colorful outdoor scenery, closing portrait, repeating "THANK YOU!" lettering, direct email link, and social channels.

---

## 🚀 Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4, Custom Scrapbook Patterns
- **Icons**: Lucide Icons
- **Interactions**: Canvas Confetti, CSS 3D Tilts, Lightbox Modal

---

## 💻 Getting Started Locally

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Open in browser
# Visit http://localhost:3000
```

---

## ☁️ Deploy to Vercel

1. Import this repository to [Vercel](https://vercel.com).
2. Framework Preset: **Next.js**
3. Build Command: `npm run build`
4. Output Directory: `.next`
5. Click **Deploy**!
